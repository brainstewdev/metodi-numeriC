# Implementazioni di algoritmi per Calcolo numerico
In questa repo ho implementato alcuni algoritmi visti nel corso di calcolo numerico in linguaggio C.

Attualmente gli algoritmi implementati sono:
- Metodo di newton per la ricerca di zeri per equazioni non lineari
- Metodo di Eulero esplicito
- Metodo di Eulero implicito
- Heun
